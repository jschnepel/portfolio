# Joey Schnepel

I'm a software engineer in Phoenix, currently working as a Process Engineer at TSMC, where I build the internal web apps and automation that keep manufacturing operations moving for customers like Nvidia, Apple, AMD, Tesla, and Intel. Before this I worked across IT, DevOps, and data roles at Intel, Infosys, and SAIC.

Most of my work lives in the full stack: React and Next.js up front, Python on the back, AWS and GCP underneath. Lately I've been spending less time on pipelines and more on AI and robotics, both in my Master's program and in a few side projects that have taken on a life of their own.
