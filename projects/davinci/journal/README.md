# Build journal: Looking Alive

A working devlog of how the reactive da Vinci was built, in order, including the parts that did not work. The premise evolved as it went (entry 9 is where it turned): what makes the character feel alive is engagement that is *earned and intentional*, not constant. The through-line stayed the same one that drove the engineering: every decision the character makes, including every choice to hold back, has to be explainable from real, logged perception, not from a script and not from vibes.

These entries are written plainly and honestly. Where a result was negative, it stays negative. Where I caught my own system doing something it could not justify, that is written down too, because catching it was the point.
