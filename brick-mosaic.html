Project Overview

PixelBrix is a full-stack web application developed as my capstone project that converts uploaded images into 48×48 LEGO-style mosaics. Users can choose from multiple color palettes (full color, grayscale, warm tones, cool tones, or earth tones) to create unique mosaic designs complete with brick counts for building with real LEGO pieces.

The application features a comprehensive admin dashboard with JWT authentication, providing real-time usage statistics, daily analytics, and session management capabilities. The public gallery allows users to share their creations with descriptions and search functionality, while maintaining privacy controls for individual sessions.

Built with modern web technologies, PixelBrix demonstrates full-stack development skills including RESTful API design, image processing algorithms, user authentication, data visualization, and containerized deployment using Docker.

Key Features

Image Upload & Processing

Upload JPG/PNG images up to 5MB and convert them to 48×48 LEGO mosaics using Pillow image processing.

Multiple Color Palettes

Choose from 5 curated palettes: Full Color, Grayscale, Warm Tones, Cool Tones, and Earth Tones for diverse artistic styles.

Brick Count Analysis

Automatic calculation of required LEGO bricks by color with before/after image comparison.

Admin Dashboard

JWT-authenticated admin panel with real-time stats, daily usage charts, palette analytics, and session management.

Public Gallery

Share creations publicly with descriptions, browse community mosaics, and search by keywords or palette.

Docker Deployment

Containerized architecture with docker-compose for easy deployment and scalability.
